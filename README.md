# Deep Signal — Rabbit R1 Creation

Original HTML/CSS/JavaScript game designed for the 240×282 Rabbit R1 Creation viewport.

## Controls
- Rabbit scroll wheel: game-specific navigation/movement
- Rabbit side click: primary action
- Touch and keyboard fallbacks for desktop testing

## Assets
The included concept-art board was generated specifically for this project. No third-party game characters, ROMs, copyrighted game art, or franchise assets are included.

## Hosting
Host the folder as static files (for example with GitHub Pages) and point a Rabbit Creation QR at `index.html`.
